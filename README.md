# ADA Insight 2.0 — Cardano (ADA)

Учебная аналитическая система на Streamlit. **Сразу показывает главную панель**, а внешние API запрашивает только после нажатия «Загрузить / пересчитать». Если API недоступен, остальные модули продолжают работать и показывают причины проблем.

## Размещение на Streamlit Community Cloud

1. Распакуйте ZIP и **загрузите содержимое папки `ADA_Insight_Cardano_FIXED` в корень своего GitHub-репозитория**. Старые `app.py`, `analytics.py`, `sources.py`, `requirements.txt`, `README.md`, `test_analytics.py` замените новыми. Также добавьте `.streamlit/config.toml`, `.gitignore`, `runtime.txt`, `test_app.py`.
2. В GitHub Desktop сделайте Commit и Push origin. Streamlit Cloud автоматически обновит подключённое приложение. Если приложение ещё не создано: Create app → репозиторий → main → `app.py` → Deploy.
3. В настройках Streamlit Cloud в Advanced settings выберите Python 3.12, если предлагается. Если установлена другая поддерживаемая версия, приложение также может работать.
4. Для ончейн-модуля: получите mainnet Project ID на https://blockfrost.io и добавьте в **Streamlit → Manage app → Settings → Secrets**:

```toml
BLOCKFROST_PROJECT_ID = "ВАШ_КЛЮЧ"
```

Никогда не загружайте секреты в GitHub. Ключ не нужен, чтобы увидеть главную страницу и проверить другие модули.

## Локальный запуск

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Тесты

```bash
python -m pip install pytest
python -m pytest -q
```

## Возможности и ограничения

* Технические индикаторы SMA20, SMA50, EMA12, EMA26, RSI14, MACD, Bollinger; объёмы, история цен.
* Фундаментальный балл: три простых сравнения рыночных метрик. Если нет всех трёх, он не рассчитывается.
* Ончейн: Blockfrost, до 8 завершённых эпох; сравнение последних трёх и трёх предыдущих по транзакциям, комиссиям и стейку. Это образовательная эвристика, а не инвестиционный сигнал.
* Новости: Google News RSS, словарная тональность; менее 30 публикаций — балл недоступен.
* Интегральный показатель скрывается, если хотя бы один из четырёх модулей недоступен.
* SQLite сохраняет историю в файловой системе облачного экземпляра: после пересоздания сервера она может исчезнуть. Экспортируйте CSV или подключите постоянную БД.
* Невозможность подключения к внешним API может быть связана с лимитами бесплатного плана, политикой сетевого доступа или временным сбоем.

Это **исправленный рабочий прототип**, не полный проект по всем пунктам учебного ТЗ: не реализованы отдельный качественный фундаментальный анализ, ручная валидация настроений и постоянное хранилище. Внешние API зависят от сетевого доступа. Программа не даёт инвестиционных рекомендаций.
