# ADA Insight — аналитическая система Cardano (ADA)

Рабочий учебный прототип с интерактивным браузерным интерфейсом и расчётами **по реальным данным, когда доступны внешние API**.

## Запуск

Установите Python 3.10 или новее. В терминале в папке проекта:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

В браузере откроется локальный адрес, обычно http://localhost:8501.

## Доступ к Cardano on-chain API

Зарегистрируйтесь на https://blockfrost.io/ и получите **mainnet project ID**. Задайте перед запуском:

```bash
# macOS/Linux
export BLOCKFROST_PROJECT_ID="ваш_ключ"
# Windows PowerShell
$env:BLOCKFROST_PROJECT_ID="ваш_ключ"
```

Без ключа остальные разделы продолжат работать; ончейн-оценка останется недоступной. Не размещайте ключи публично.

## Источники и обновление

- CoinGecko REST API: цена, объёмы, Market Cap, FDV, предложение, от 30 до 365 дней истории; кеш 15 минут.
- DefiLlama REST API: TVL Cardano; кеш 30 минут.
- Blockfrost REST API: блок и текущая эпоха, транзакции, комиссии, стейк; кеш 30 минут; необходим API-ключ.
- Google News RSS: заголовки публикаций с поисковой фильтрацией Cardano; кеш 30 минут.

Данные приходят по HTTPS в JSON, кроме RSS (XML). Лимиты, региональные ограничения, изменения схемы API, задержки и отсутствие отдельных метрик могут прервать обновление. Программа сообщает об этом пользователю.

## Расчёты

- SMA20/SMA50: простое среднее за 20/50 наблюдений.
- EMA12/EMA26: экспоненциальное среднее, adjust=False.
- MACD: EMA12 − EMA26; Signal: EMA9(MACD).
- RSI14: сглаженные по Уайлдеру средние положительных/отрицательных приращений.
- Полосы Боллинджера: SMA20 ± 2×std20.
- Технический балл: четыре учебных условия по 25 пунктов (цена/SMA20, MACD/Signal, RSI, SMA20/SMA50).
- Фундаментальный балл: 3 условия (капитализация/FDV, циркулирующее/максимальное предложение, TVL/капитализация). Эти пороги субъективны, не заменяют полноценный качественный фундаментальный анализ.
- Ончейн: отображается реальный снимок эпохи, но **динамика и ончейн-балл ещё не реализованы** (необходимо получить несколько эпох).
- Сентимент: словарный анализ англоязычных новостных заголовков; если найдено менее 30 публикаций, показатель не выдаётся.
- Интегральная оценка: 0.30·TA + 0.25·FA + 0.25·ON + 0.20·SA. Если какой-то модуль без валидной оценки, результат подавляется, а не подменяется нулём. Отдельно показывается доля модулей с расчётом, а не подтверждённая статистическая точность.

## Хранилище и воспроизводимость

После нажатия «Сохранить этот расчёт» программа сохраняет JSON оценки и дату в локальную SQLite-базу `ada_insight.sqlite3`. Кеш внешних API и изменение данных у поставщиков могут приводить к разным значениям при повторной загрузке того же периода.

## Текущее состояние и ограничения

Это **работающий прототип**, но **пока не готовый полный вариант для сдачи всей практической работы**. Для соответствия всем требованиям PDF необходимо добавить: историю ончейн-метрик минимум по трём показателям с графиками и сравнением с ценой; полную фундаментальную матрицу с качественными экономическими последствиями; сохранение сырых снимков всех источников для воспроизводимости; точный Confidence Score по полноте, возрасту и надёжности; динамику новостных настроений; ручную валидацию 20% новостей; проверку аномалий/устаревания и расширенные тесты; схемы архитектуры, ТЗ, отчёт, инструкцию и презентацию защиты. Не следует представлять неготовые функции как реализованные.
